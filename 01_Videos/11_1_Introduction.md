# Video 11.1: Introduction

## Summary

This video introduces the concepts of client-server architecture and distributed computing.

The module focuses on communication between web browsers and web servers using HTTP. Students are introduced to Flask, a Python web framework used for building web applications.

Additional topics covered throughout the module include cookies, Bootstrap, REST APIs, Swagger, security technologies, OAuth2, and Okta.

## Key Concepts

### Client

A client is a device or software application that requests services or information from a server.

Examples:

- Web browsers
- Mobile applications
- Desktop applications

### Server

A server is a system that processes requests and provides resources or services to clients.

Examples:

- Web servers
- Application servers
- Database servers

### HTTP

Hypertext Transfer Protocol is the communication method used between clients and servers on the web.

Common actions include:

- Requesting web pages
- Sending form data
- Retrieving API responses

### Distributed Computing

Distributed computing allows processing and communication to be divided across multiple systems, enabling scalability and efficiency.

## Key Takeaway

Client-server architecture forms the foundation of modern web applications. Understanding how clients, servers, and HTTP communicate is essential for building secure and scalable software systems.
