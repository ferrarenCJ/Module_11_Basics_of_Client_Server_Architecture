# Module 11 Glossary

## Client

A software application or device that sends requests to a server.

## Server

A computer or application that processes requests and returns responses.

## HTTP

Hypertext Transfer Protocol used for communication between clients and servers.

## Flask

A lightweight Python web framework used to build web applications.

## Cookie

Data stored by a website to maintain information about a user.

## Session Cookie

A temporary cookie used to manage user sessions.

## Bootstrap

A front-end framework used to create responsive web interfaces.

## REST API

An interface that allows applications to communicate using HTTP requests.

## Swagger

A tool used to document and test REST APIs.

## OAuth2

An authorization framework for secure application access.

## Okta

An identity and access management platform supporting OAuth2 authentication.
